# Icons for NegotiAI Coach Extension

Pour créer les icônes, utilisez un outil comme:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/
- Ou Photoshop/GIMP

## Tailles requises

- **icon16.png** : 16x16px (barre d'outils)
- **icon48.png** : 48x48px (page extensions)
- **icon128.png** : 128x128px (Chrome Web Store)

## Design suggéré

Logo avec :
- Fond dégradé violet/bleu (#667eea → #764ba2)
- Icon: 🎯 ou symbole de négociation
- Style moderne, coins arrondis

## Placeholder temporaire

En attendant vos icônes, l'extension utilise l'icône par défaut du navigateur.

Pour ajouter vos icônes:
1. Créez les 3 tailles
